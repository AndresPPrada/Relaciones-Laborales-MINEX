# MINEX V22

- ID de casos asignado automáticamente como consecutivo numérico: nuevo caso = máximo ID existente + 1.
- El ID no es editable manualmente.
- Los casos importados sin ID reciben consecutivo automáticamente.
- Se conserva el ID existente al editar un caso.
- La tabla de casos muestra Detalle de la solicitud de forma prominente.
- La vista previa de importación de casos incluye Detalle de la solicitud.
- La lógica de selección múltiple, duplicados, empleados y seguimientos se conserva de V21.
