# MINEX | Gestión de Relaciones Laborales — V13

Versión frontend para GitHub Pages, basada en IndexedDB.

## Mejoras
- Dashboard ejecutivo ampliado con KPIs, alertas de calidad, evolución mensual, estado, áreas, requerimientos, responsables y empresas.
- Informes ampliados por área, empresa, requerimiento, responsable y mes.
- Detalle por área con casos, cerrados, en seguimiento, vencidos y % de cierre.
- Exportación consolidada a Excel.
- Vista completa de los 18 campos de empleados con edición individual.
- Formularios de edición de casos con campos operativos y de dashboard.
- Seguimientos y filtros de vencidos/hoy/semana laboral.
- Persistencia local con IndexedDB.
- Carga y exportación Excel/CSV.

## GitHub Pages
Subir el contenido de esta carpeta al root del repositorio. `index.html` debe quedar en la raíz.

## Datos
La aplicación contiene datos laborales de referencia. No publicar un repositorio con información personal en modo público.
