# MINEX V20

Ajustes de interfaz y ficha de casos:
- La tabla principal de Casos muestra ahora `Detalle de la solicitud` con ancho prioritario, truncado inteligente y texto completo al pasar el cursor.
- Se elimina de la interfaz la sección redundante `Historial de seguimientos`; la bitácora queda centralizada en `Desarrollo del caso`.
- Se mantiene `Último seguimiento` como resumen operativo y la sección para registrar el nuevo seguimiento.
- Se conserva la lógica de fechas, estado, cierre y edición de la versión anterior.
