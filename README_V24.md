# MINEX V24

- Se elimina el módulo independiente de Volumetrías.
- La volumetría se entiende como análisis estadístico de la base maestra de Casos.
- Informes incorpora filtros por empresa, área, requerimiento, estado y periodo.
- Indicadores, distribuciones y reportes respetan los filtros del análisis.
- Seguimientos incluye Detalle de la solicitud.
- Exportación consolidada incluye resumen, análisis por dimensiones y detalle de casos.
